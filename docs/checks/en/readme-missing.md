# readme-missing – No README

**Category:** Maintenance · **Severity:** LOW · **Automatic fix:** yes

## What the check looks for

There is no `README*` in the repository root.

## Why it matters

Without a README, in half a year you will not know what the repo is for and how to run it.

## Steps

1. The fix (`f`) creates a README skeleton from the repo name and the detected ecosystem.
